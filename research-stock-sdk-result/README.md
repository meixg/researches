# Stock SDK 调研报告

本文档对 [stock-sdk](https://github.com/chengzuopeng/stock-sdk) 项目进行了深度调研，涵盖依赖分析、数据源调查、价格准确性验证及使用成本评估。

## 1. 项目基本情况

- **核心定位**：为前端和 Node.js 设计的股票行情 JavaScript SDK。
- **运行环境**：支持浏览器（通过 Fetch/JSONP）和 Node.js 18+。
- **主要特性**：零运行时依赖、全市场覆盖（A股/港股/美股/基金/期货/期权）、支持技术指标计算。

## 2. 依赖与数据源分析

### 依赖关系
- **运行时依赖**：**0** (Zero Dependencies)。
- **开发依赖**：tsup (构建), vitest (测试), msw (Mock), vitepress (文档)。
- **分析结论**：项目极其轻量，不会引入额外的安全风险或包体积负担。

### 数据源调查
SDK 聚合了多个主流财经平台的公开 API：
- **腾讯财经 (gtimg.cn)**：主要用于实时行情、分时数据、搜索和代码列表。
- **东方财富 (eastmoney.com)**：主要用于 K 线数据、板块行情、资金流向、北向资金、基金深度数据和期货。
- **新浪财经 (sina.com.cn)**：主要用于期权数据。
- **自定义静态资源 (linkdiary.cn)**：用于存储全市场代码列表和交易日历，减少对动态接口的压力。

## 3. 使用成本与限制

- **财务成本**：**免费**。使用公开 API，无需支付订阅费用。
- **技术成本**：极低。TypeScript 原生支持，提供完整的类型定义。
- **限制与治理**：
  - **限流**：默认 5 req/s（令牌桶算法）。
  - **稳定性**：内置熔断器（连续 5 次失败触发 30s 熔断）和指数退避重试机制。
  - **延迟**：非实时撮合行情，通常有数十秒到数分钟延迟。

## 5. 其他使用建议

### AI / MCP 集成
项目配套了 `stock-sdk-mcp`，可直接接入 **Cursor**、**Claude Desktop** 等 AI 助手。
- **Tools**: 32 个预置工具，覆盖所有 API。
- **Skills**: 4 个专家级 Skill（技术分析、选股、概览、监控）。

### 最佳实践
1. **代码搜索**：如果不确定代码，优先使用 `sdk.search(keyword)`。
2. **复权处理**：获取 K 线时默认提供前复权 (`qfq`)，若需计算长期收益，请根据需要调整 `adjust` 参数。
3. **缓存建议**：基金历史净值等大数据量接口建议在应用层增加持久化缓存。
