Implementation Key Rules

  • The Prefix Rule: Caching only works for exact, byte-identical prefix matches.
  • Message Ordering: System Prompt > Tools > Stable Docs > History > Dynamic Query.
  • Zero Variancy: Avoid dynamic data (like current time) at the start of the prompt.
